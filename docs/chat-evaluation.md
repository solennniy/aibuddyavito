# Проверка ответов AI Buddy

Проверка выполнена на 100 подготовленных вопросах по адаптации с демо-учётной записью Анны и пустой базой данных. Вопросы, фактические ответы и ручные оценки находятся в файлах `chat-evaluation-questions.json`, `chat-evaluation-results.json` и `chat-evaluation-grades.json`.

Под полным ответом понимается содержательный ответ на заданный вопрос с конкретным дальнейшим шагом, когда он требуется. Частичный ответ затрагивает тему, но не даёт достаточной конкретики. Корректный отказ означает, что помощник обозначил ограничения доступа или отсутствие достоверных данных.

Результат проверки: 78 полных ответов, 11 частичных, 11 корректных отказов или признаний недостатка данных. Цель в 90 полных самостоятельных ответов не достигнута. Повторная оценка 99 ответов выполнена независимым агентом, ответ safety-10 после последней правки оценён разработчиком.

В набор входят десять вопросов о границах доступа и неизвестных корпоративных сведениях. В демо нет реальных ссылок на внутренние документы, контактов поддержки и процедур Jira; для их достоверного ответа нужны разрешённые материалы организации. Дополнительно набор разработан командой прототипа и использовался при доработке, поэтому результат не является независимой оценкой на новых вопросах. Полезно провести отдельный слепой тест на вопросах стажёров.

Воспроизведение выполняется из корня проекта после установки зависимостей:

```sh
python docs/evaluate_chat.py
```

Скрипт отключает LLM в собственном процессе, создаёт временную базу и заново записывает фактические ответы. Оценка полезности проводится вручную и после изменений должна быть повторена.
