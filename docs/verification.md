Окружение проверки: Python 3.11.9, Node.js 26.13.1, Playwright 1.56.1, Microsoft Edge 157. Серверные тесты охватывают права, сохранение при перезапуске, идемпотентность, ограничения модели и закрытие задачи чек-листа после выдачи доступа. Отдельный набор поднимает локальный HTTP-сервер и проверяет режим модели по-настоящему: заголовок авторизации и тело запроса, выбор разрешённого источника, честное `none`, отказ следовать редиректу, ответ об ошибке, повреждённый JSON и нестроковый ответ модели. Браузерный тест проверяет весь сценарий от задачи на панели до учебного источника, черновика, контролируемого сбоя, повтора и сохранённого номера заявки. После обновления страницы номер остаётся в истории. Повтор подтверждения возвращает тот же номер. Другой стажёр не может подтвердить чужую заявку и не видит её в своей истории. Мобильный тест проверяет отображение панели на ширине 375 пикселей и не зависит от состояния, оставленного другими тестами.

Команды и расположение отчётов указаны в [README](../README.md). Docker CLI в рабочем окружении недоступен, поэтому образы локально не собирались: сборка и запуск контейнера API выполняются в GitHub Actions. Остальные проверки пройдены локально и повторяются там же.
