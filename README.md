# AI Buddy

Прототип для Hack&Change 2026. Помогает стажёру пройти чек-лист, задать вопрос по учебным инструкциям и оформить заявку на доступ. Наставник видит заявки закреплённых стажёров и может общаться с ними.

Пользователи, инструкции и сервис заявок учебные. Демо работает без API-ключа.

## Быстрый запуск

Установите и запустите Docker Desktop. В папке проекта выполните:

```sh
docker compose up --build
```

Откройте [http://localhost:5173](http://localhost:5173). Остановка — Ctrl+C. Данные останутся в томе Docker `buddy-data`.

## Запуск без Docker

Нужны Python 3.11 и Node.js 24. В Windows PowerShell из папки проекта:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r backend/requirements-test.txt
.\.venv\Scripts\python.exe -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

Оставьте терминал открытым. Во втором терминале:

```powershell
cd frontend
npm ci
npm run dev
```

Откройте [http://localhost:5173](http://localhost:5173). На Linux и macOS вместо `.venv\Scripts\python.exe` используйте `.venv/bin/python`. База хранится в `data/aibuddy.sqlite3`.

## Как проверить

1. Откройте профиль и выберите Анну. Демо-пользователям пароли не нужны.
2. Откройте «Сообщения» → «AI Buddy». Спросите, как получить доступ к пространству команды, и откройте источник.
3. Нажмите «Создать заявку», укажите причину, проверьте черновик и подтвердите отправку. Обновите страницу и проверьте номер заявки.
4. В профиле Марии откройте «Заявки стажёров» и согласуйте заявку. Вернитесь к Анне и нажмите «Демо: подтвердить выдачу доступа».
5. В чате с AI Buddy напишите «Я познакомилась с командой» и подтвердите выполнение. Отметка появится в чек-листе.
6. Напишите пять вопросов, на которые в учебной базе нет ответа. Появится кнопка «Написать наставнику». Вопросы попадут в черновик, который можно отредактировать и отправить. Счётчик сбрасывается после ответа по инструкции и при смене профиля.
7. Откройте чат Ивана и отправьте сообщение. Переключитесь на Ивана и проверьте переписку с Анной.

При пяти последовательных вопросах без подходящей инструкции помощник предлагает наставника. Ошибка сервиса не считается вопросом без ответа. Переписка с наставником и стажёрами сохраняется. Учебная поддержка сохраняет обращения, но сотрудники поддержки к демо не подключены.

## Подключение модели

Без ключа работает деморежим с ответами по учебным инструкциям. Для модели скопируйте `.env.example` в `.env` и заполните `LLM_API_URL`, `LLM_API_KEY` и `LLM_MODEL`. Нужен полный адрес OpenAI-совместимого Chat Completions API. После изменения файла выполните `docker compose up -d --force-recreate api`. При запуске без Docker задайте эти переменные в терминале перед запуском сервера.

Сервер передаёт модели только доступные пользователю инструкции. Результат модели проверяется по источнику и цитате, но смысловую точность ответа эта проверка не гарантирует. Статусы и операции выполняются сервером.

## Тесты

В корне проекта:

```powershell
.\.venv\Scripts\python.exe -m coverage run --source=backend --omit='*/tests/*' -m pytest backend/tests
.\.venv\Scripts\python.exe -m coverage report --precision=2 --show-missing --fail-under=80.01
.\.venv\Scripts\python.exe -m coverage xml
```

Для интерфейса и браузерной проверки:

```powershell
cd frontend
npm run build
npm run test:coverage
npx playwright install chromium
$env:PYTHON = (Resolve-Path ..\.venv\Scripts\python.exe).Path
npm run test:e2e
```

На Linux и macOS перед браузерным тестом задайте `export PYTHON="$(cd .. && pwd)/.venv/bin/python"`. Playwright запускает отдельные серверы на портах 8017 и 5177.
